# 阿瓦隆 UI 拆分资产

本目录将 16 张 750×1334 的竖屏微信小游戏界面拆为可复用生产资产。

## 目录约定

- `00-共享资产`：全局可复用的背景、Logo、面板、按钮、图标、头像、身份徽记和装饰。
- `01-登录界面` 至 `16-好友列表界面`：每页保留原始 UI，并放入该页实际会使用的资产副本。
- `00-原始UI`：参考成图，不直接从中裁切生产素材。
- `09-拆分预览`：用于检查该页拆分资产的联系表或合成预览，不作为运行时素材。

## 制作原则

- 所有页面背景统一为 750×1334 PNG。
- UI 组件、按钮、图标、头像、身份徽记、Logo 和装饰必须保留真实 Alpha 透明通道。
- 文字、倒计时、房间号、玩家名、段位、票数和动态数值不烘焙进按钮或面板，应由游戏运行时字体绘制。
- 风格使用暗黑中世纪阿瓦隆：深炭黑与冷深蓝为主，暗石材与皮革为辅，少量哑光旧铜描边，避免大面积亮金属和强高光。
- 页面目录中的文件是便于开发直接取用的副本；资产母版以 `00-共享资产` 为准。

详细页面映射见 `ASSET_MANIFEST.md`。
