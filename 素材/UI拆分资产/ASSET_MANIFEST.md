# 16 页 UI 资产映射

尺寸基准：竖屏微信小游戏 750×1334。背景为完整场景图；其余 PNG 为可叠加的透明组件。文件名以共享母版为准，页面目录内为开发便捷取用的副本。

## 全局母版

| 类别 | 目录 | 用途 |
|---|---|---|
| 背景 | `00-共享资产/01-背景` | 8 套环境背景，按页面组复用 |
| Logo/徽章 | `00-共享资产/02-Logo` | 游戏标题、善/恶阵营徽章 |
| 面板 | `00-共享资产/03-面板` | 标题条、内容面板、弹窗、列表行、任务 HUD、搜索框、底部导航 |
| 按钮 | `00-共享资产/04-按钮` | 主按钮、次按钮、危险按钮、登录按钮、小型动作按钮及页面专用卡片 |
| 图标 | `00-共享资产/05-图标` | 导航、状态、操作、投票、计时、分享和社交图标 |
| 头像 | `00-共享资产/06-头像` | 角色半身头像、空缺席位剪影 |
| 身份徽记 | `00-共享资产/07-身份徽记` | 梅林、派西维尔、忠臣、刺客、莫甘娜、爪牙、奥伯伦、莫德雷德 |
| 装饰 | `00-共享资产/08-装饰` | 阵营旗、渡鸦、冠饰、分隔纹样、奖牌等 |

## 页面映射

### 01 登录界面

- 背景：`bg-main-hall-750x1334.png`
- Logo：`game_logo_title.png`
- 面板/按钮：登录按钮、游客按钮、标题/分隔装饰
- 图标：声音、设置
- 动态文字：微信登录、游客体验、版本号由运行时字体绘制

### 02 主界面

- 背景：`bg-main-hall-750x1334.png`
- Logo/头像：游戏标题、玩家头像与头像框
- 按钮：开始匹配、创建房间、加入房间、训练/说明入口
- 面板：底部导航、标题条
- 图标：主页、排行榜、好友、设置、声音、邀请/剑

### 03 匹配中界面

- 背景：`bg-round-table-hall-750x1334.png`

- 按钮/图标：取消匹配、返回、计时器

### 04 房间准备界面

- 面板：房间标题、圆桌席位、房间状态弹窗
- 头像：房间玩家与空缺席位

### 06 身份确认界面

## 运行时层说明

房间号、玩家名、轮数、倒计时、胜率、段位、票数、AI 文案和按钮标签不做成不可编辑的图片。它们应在运行时以项目字体、字号、颜色和阴影规范叠加；这样同一套透明底图可以服务于不同局面和多语言版本。
