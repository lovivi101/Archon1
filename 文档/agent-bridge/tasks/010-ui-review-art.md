## 做法

1. 开始前确认以上 4 个文件都不存在；若某个已存在，跳过不要覆盖，并在报告里写明。
2. 先查看参考图：`assets/ui/tier-1-bronze.png`、`tier-2-silver.png`、`tier-3-gold.png`（构图基准）、`mission-success-emblem.png`、`crown-icon.png`、`target-icon.png`（材质基准）。
3. 一次只出一张：生成 → 去背景 / 缩放到目标尺寸 → 检查（尺寸、四角 alpha、主体未被裁切、留白、无文字）→ 合格再做下一张；不合格重画这一张。
4. 第 1、2 张出完后，把 `tier-1-bronze-v2`、`tier-2-silver-v2`、`tier-3-gold` 三张各缩到 32×32 和 42×42 并排放在深色背景（#0e1117）上，自己确认三者在 32px 下能区分；不能区分就重画。
