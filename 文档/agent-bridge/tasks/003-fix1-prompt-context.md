# 003-fix1 LLM 提示缺少当前局面，夜晚视野含义不明

- 类型：bug（任务 003 审核意见）
- 范围：`服务器端/AvalonTsServer/src/llm/agent.ts`、`src/llm/provider.ts`、`scripts/llm-test.js`
- 不要改动：`src/rules.ts`、`src/ai.ts`、`src/game.service.ts`、客户端

## 审核发现（Claude）

### 1. 投票时不告诉模型当前提案的队伍（严重）

`buildPrompt()` 只给了历史提案（`room.proposals`，只包含已经投完票的），**正在投票的队伍 `room.selectedSeats` 没有出现在提示里**。模型在不知道队伍是谁的情况下投票。

### 2. 缺少当前局面

提示中需要明确给出（按动作选择相关项）：

- 总人数、当前第几轮、当前队长座位、本轮需要的队伍人数（具体数字，不要写“按人数表”）；
- 已连续否决次数（第 5 次否决坏人直接获胜）；
- 已完成任务的成功/失败数（例如“好人 1 胜，坏人 1 胜”）；
- 出任务时：本轮需要几张失败牌才算失败（`failsRequired`），以及队伍里有谁；
- 刺杀时：候选座位列表（排除自己和已知队友）。

### 3. 夜晚视野没有说明含义

现在统一写“夜晚确认的座位（仅这些）”。不同身份含义不同，必须按身份解释：

| 身份 | 视野含义 |
| --- | --- |
| 梅林 | 这些座位是坏人（莫德雷德除外，你看不到他） |
| 派西维尔 | 这两个座位一个是梅林、一个是莫甘娜，你不知道哪个是哪个 |
| 刺客/莫甘娜/爪牙/莫德雷德 | 这些座位是你的坏人同伴（奥伯伦除外，你们互不相识） |
| 奥伯伦 | 你看不到任何人，其他坏人也不知道你 |
| 忠臣 | 你没有夜晚信息 |

### 4. 规则文本

直接写出本局人数对应的五轮队伍人数（从 `TEAM_SIZES` 取），以及“第 4 轮需要两张失败牌”是否适用于本局人数。

### 5. provider 小问题

- `apiKey` 为空时应在构造或首次调用时直接抛出明确错误（“未配置 LLM key”），不要带着空 Bearer 发请求。
- 网络层错误（`fetch` 抛出的 `TypeError`，如连接被重置）应与 5xx 一样按退避重试。

### 6. 座位编号

提示里统一说明“座位号从 0 开始”，历史、视野、候选列表都用同一套编号，并在每个座位后带昵称，例如 `2号(林中旅人)`。

## 测试（加入 `scripts/llm-test.js`）

- 投票提示中包含当前提案队伍的全部座位号；
- 出任务提示中包含本轮需要的失败牌数；
- 梅林/派西维尔/坏人/奥伯伦/忠臣五种身份的视野说明各不相同，且与上表一致；
- 忠臣的提示中仍不含其他玩家的身份；
- 空 key 时抛出错误且信息中不含 “Bearer”；
- `fetch` 抛 `TypeError` 后重试成功。
