# 分享与邀请

代码在 `scripts/services/share_service.gd`（`AvalonShare`，由 `AvalonApp.share` 持有），界面入口在 `page_view.gd`，测试是 `tools/smoke_share.gd`。

## 玩家能做什么

| 位置 | 按钮 | 作用 |
| --- | --- | --- |
| 联机房间（04 页，开局前） | 邀请好友 | 发送房间邀请：“【阿瓦隆：暗影对决】邀请你加入 7 人局，房间号 123456（湖中仙女、第4轮需2张失败票）……” |
| 联机大厅（03 页） | 粘贴 | 从剪贴板里找出 6 位房间号填入。直接把整段邀请文字粘进输入框再点“加入”也可以 |
| 结算（13 页）、复盘（14 页，本局或服务端战绩） | 分享战绩 | 生成 750×1000 的战绩图（胜负、我的身份、五轮任务、结束原因、段位分变化、全员身份），弹出预览，再按平台分享 |

从邀请进入游戏时（见下文的启动房间号），登录后直接进入联机大厅并填好房间号，只需点“加入”。

## 各平台行为

`AvalonShare.platform()` 判断当前平台：

| 平台 | 邀请 | 战绩图 | 启动房间号 |
| --- | --- | --- | --- |
| 桌面（Windows / macOS / Linux） | 复制到剪贴板 | 保存到“图片/Avalon/”，战绩文字复制到剪贴板 | 命令行 `-- room=123456` |
| Android（无插件） | 复制到剪贴板 | 尝试保存到“Pictures/Avalon/”，战绩文字复制到剪贴板 | — |
| Android（有 `AvalonShare` 插件） | 系统分享面板 + 复制 | 系统分享面板 | 可由插件扩展 |
| Web | 复制到剪贴板，文字附带 `?room=123456` 链接 | 保存到 `user://`，战绩文字复制 | 网址参数 `?room=123456` |
| 微信小游戏 | `wx.shareAppMessage`，卡片带 `room=123456` 查询参数 | 截取预览区域 `canvas.toTempFilePathSync` 作为分享图 | `wx.getLaunchOptionsSync().query.room` |

所有平台都会把战绩图另存一份到 `user://avalon-share.png`。

### 微信小游戏

通过 godothub/godot-minigame 导出后，游戏运行在带全局 `wx` 对象的 Web 环境中，`AvalonShare` 用 `JavaScriptBridge.eval` 调用微信接口：

- 启动时调用 `wx.showShareMenu` 打开右上角“转发 / 分享到朋友圈”，并用 `wx.onShareAppMessage`、`wx.onShareTimeline` 读取 `globalThis.__avalonShare`。进入房间时它被设为该房间的邀请（标题 + `room=房间号`），离开房间后恢复为游戏名。
- “邀请好友”直接调用 `wx.shareAppMessage`。好友点卡片冷启动游戏时，`launch_room_code()` 从 `wx.getLaunchOptionsSync().query.room` 读出房间号。
- “分享战绩”截取屏幕上预览图所在区域作为 `imageUrl`。微信分享卡片推荐 5:4，3:4 的战绩图会被裁切显示上半部分（标题、胜负、身份）。

**注意：** 以上微信部分按微信小游戏 API 编写，尚未在真机或微信开发者工具中验证。需要确认的点：godot-minigame 下 `JavaScriptBridge` 是否可用、主画布是 `canvas` 还是 `GameGlobal.canvas`、截图坐标是否需要乘以 `devicePixelRatio`。小游戏热启动（从后台切回时点了邀请卡片）需要再监听 `wx.onShow` 读取 `query.room`，目前未处理。

### Android 分享插件接口

Godot 本身不提供 Android 系统分享面板。需要时编写一个 Godot Android 插件（v2），单例名为 `AvalonShare`，提供两个方法：

```kotlin
@UsedByGodot fun shareText(title: String, text: String)
// path 是 PNG 的绝对路径（user:// 已转换）；插件需通过 FileProvider 暴露给其他应用
@UsedByGodot fun shareImage(path: String, title: String, text: String)
```

实现即 `Intent.ACTION_SEND` + `Intent.createChooser`。插件存在时 `platform()` 返回 `android_plugin`，按钮文字变为“分享给好友”；不存在时退回剪贴板和保存图片，按钮文字为“复制战绩文字”。

## 测试

```bash
xvfb-run -a godot --path . --audio-driver Dummy --script res://tools/smoke_share.gd -- room=654321
```

覆盖：房间号识别、邀请文字、本地练习拒绝邀请、联机邀请写入剪贴板并能粘贴回来、启动参数房间号、本地 7 人局打完后生成战绩图（保存为 `verification/share_card.png`）、结算页预览与分享按钮、服务端复盘生成战绩数据、带邀请登录后进入大厅。需要真实渲染，不能用 `--headless`。
