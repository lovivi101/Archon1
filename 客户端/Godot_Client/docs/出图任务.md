# 出图任务（交给一个 Codex 智能体按顺序完成）

只开一个 Codex 智能体，按下表顺序一张一张生成，每张完成后再做下一张。图片模型用 `gpt-image-2.5-flare`，Codex 模型用 `gpt-6-sol`（推理强度默认 high）。

## 在你的电脑上运行

在仓库根目录（PowerShell）：

```powershell
git pull
codex exec -m gpt-6-sol -c model_reasoning_effort="high" --full-auto "按 客户端/Godot_Client/docs/出图任务.md 的要求和顺序出图，图片模型用 gpt-image-2.5-flare，一次只处理一张，每张检查合格后再做下一张"
```

只运行这一条命令（一个 Codex 智能体）。完成后提交并推送 `assets/ui/` 下的新图（以及 Godot 生成的 `.import` 文件之外的内容，`.import` 不入库）。

## 通用要求

- 画风：暗色哥特亚瑟王题材的手游 UI。材质是铁灰/枪铁色金属 + 古金描边浮雕；好人相关用深蓝点缀，坏人相关用暗红点缀；质感和 `assets/ui/mission-success-emblem.png`、`crown-icon.png`、`target-icon.png` 一致。生成前先看这几张参考图。
- 除 `share-card-bg.png` 外，全部为**透明背景 PNG**、主体居中、四周留 6% 空白，不要文字、不要水印、不要投影到画布边缘。
- 输出到 `客户端/Godot_Client/assets/ui/`，文件名严格按下表。已有同名文件不要覆盖，先停下来询问。
- 每张图生成后检查：尺寸正确、背景透明（四角像素 alpha 为 0）、主体没有被裁切。不合格就重画这一张，不要继续下一张。
- 全部完成后，在 `客户端/Godot_Client` 目录运行一次 `godot --headless --path . --import`，让 Godot 生成导入文件。
