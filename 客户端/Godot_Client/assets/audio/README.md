# 音频素材清单

播放代码已经接好（`scripts/services/audio_service.gd`）。把文件按下面的名字放进对应目录即可生效，**不需要改代码**；缺少的文件会被静默跳过，游戏照常运行。

```
assets/audio/
├── sfx/     音效：sfx/<名字>.ogg
└── music/   音乐：music/<名字>.ogg
```

## 格式要求

| 项目 | 建议 |
|---|---|
| 文件格式 | 优先 **OGG Vorbis**（`.ogg`）；也支持 `.wav`、`.mp3`。同名时按 ogg → wav → mp3 的顺序取第一个 |
| 采样率 | 44.1 kHz 或 48 kHz |
| 声道 | 音效用单声道即可，音乐用立体声 |
| 音效响度 | 峰值不超过 -3 dBFS；同类音效之间音量要接近；开头不要留空白 |
| 音乐响度 | 约 -16 LUFS（手机外放舒适）；循环曲首尾要能无缝衔接 |
| 文件大小 | 音效每个尽量小于 100 KB；背景音乐每首尽量小于 2 MB（OGG 质量 4～5 即可） |
| 命名 | 必须与下表完全一致（小写英文和下划线） |

放入文件后，用 Godot 编辑器打开一次项目（或执行 `--import`）完成导入，再运行下面的命令检查缺哪些：

```powershell
& 'E:\Game_Work\Godot\Godot_v4.7.2-stable_win64_console.exe' --headless --path . --script res://tools/audio_check.gd
```

## 背景音乐（`music/`）

按页面自动切换，两首之间约 0.8 秒交叉淡入淡出。

| 文件名 | 播放时机 | 循环 | 风格与时长建议 |
|---|---|---|---|
| `bgm_lobby` | 登录页、主界面、联机大厅、房间、排行榜、好友、设置 | 是 | 暗黑中世纪、舒缓，管风琴/弦乐铺底，1～2 分钟 |
| `bgm_table` | 对局中：分配身份、发言、组队、投票、任务、结果、湖中仙女 | 是 | 低沉、有悬疑感但不抢戏，便于大家阅读发言，2～3 分钟 |
| `bgm_assassination` | 刺杀阶段（坏人亮明身份后） | 是 | 紧张、鼓点渐强，1 分钟左右 |
| `victory` | 结算页，你所在阵营获胜 | 否 | 胜利号角短曲，5～10 秒 |
| `defeat` | 结算页，你所在阵营失败 | 否 | 低沉收尾短曲，5～10 秒 |

## 设置

个人设置页有三个开关：全部静音、音乐、音效，分别对应 Godot 的 `Master`、`Music`、`SFX` 音频总线，设置会保存在本机。

## 新增声音的做法

1. 在 `scripts/services/audio_service.gd` 的 `SFX_NAMES`（或 `MUSIC_NAMES`）里加上名字；
2. 在合适的位置调用 `AvalonApp.audio.play_sfx("名字")`，或在 `AvalonController._play_cue` 里按协议事件触发；
3. 在本表补一行说明。
